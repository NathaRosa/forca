# Forca

Jogo da Forca desenvolvido em Java.

O projeto consiste em uma implementação do clássico jogo da forca, no qual o jogador precisa descobrir uma palavra secreta tentando acertar suas letras antes que o número máximo de tentativas seja atingido.

## Funcionalidades

* Seleção de uma palavra para o jogo.
* Tentativas de descoberta das letras.
* Exibição das letras já descobertas.
* Controle de tentativas disponíveis.
* Verificação de acertos e erros.
* Identificação de vitória ou derrota.
* Exibição do resultado ao final da partida.

## Tecnologias

* Java

## Objetivo

Projeto desenvolvido para praticar conceitos fundamentais de Java, incluindo estruturas condicionais, estruturas de repetição, manipulação de strings, arrays, entrada de dados e lógica de programação.

O projeto também serve como base para futuras melhorias e implementação de novos recursos.
